# 详细说明（编译 / 发布 / 服务端）

> 这份文档只随源码压缩包提供，仓库 README 里不展开，免得显得啰嗦。

## 环境要求

| 项目 | 版本 |
|---|---|
| Android Studio | Ladybug 或更新 |
| JDK | 17 |
| Android Gradle Plugin | 见 `gradle/libs.versions.toml` |
| minSdk / targetSdk | 24 / 34 |
| Kotlin | 见 `gradle/libs.versions.toml` |

## 构建

1. 用 Android Studio 打开项目根目录（或命令行执行下面步骤）
2. 在根目录建 `local.properties` 指向本机 SDK：

   ```properties
   sdk.dir=/path/to/Android/Sdk
   ```

   > Windows 示例：`sdk.dir=C\:\\Users\\你的用户名\\AppData\\Local\\Android\\Sdk`

3. 编译：

   ```bash
   ./gradlew assembleDebug      # 调试包
   ./gradlew assembleRelease    # 发布包（需自行配置签名）
   ```

## 发布签名

发布包需要自己的签名。在 `app/build.gradle` 里配置 `signingConfigs`，
keystore 放在项目内但**不要提交到仓库**：

```gradle
signingConfigs {
    release {
        storeFile file("your.keystore")
        storePassword "******"
        keyAlias "******"
        keyPassword "******"
    }
}
```

## 服务端地址配置

客户端需要连接音乐聚合服务，默认是占位符：

```
YOUR_API_BASE_URL              # 业务后端（账号 / 收藏 / 歌单 / 公告）
YOUR_API_BASE_URL/music-api    # 音乐聚合服务（搜索 / 播放地址 / 歌词）
```

搜索代码里的 `MusicApiPrefs`（或 `API_BASE_URL` 常量），替换成你自己的服务地址。
音乐聚合服务可自行部署（如开源的 `go-music-api` 类项目）。

## 已知说明

- 音乐数据来自第三方公开接口，本项目**不存储任何音乐文件**
- 部分平台的完整播放需要登录对应平台账号（用你自己的账号即可）
- 未登录 / 无会员时，部分歌曲会提示"暂无免费音源"
